# Two-Stage Operational Amplifier Design

## Overview
Designed and simulated a two-stage operational amplifier focusing on high gain, bandwidth, and stability.

## Performance Specifications
- **Voltage Gain:** 71 dB
- **Gain-Bandwidth Product (GBW):** 11 MHz
- **Phase Margin:** 45°
- **Slew Rate:** 20 V/µs

## Key Features
- Implemented a two-stage amplifier architecture.
- Integrated a nulling resistor for improved frequency compensation and stability.
- Analyzed gain variations across different circuit components.
- Evaluated frequency response and amplifier performance.

## Tools & Technologies
- CMOS Analog Circuit Design
- Circuit Simulation
- AC and Transient Analysis

## Conclusion
Successfully designed and analyzed a two-stage operational amplifier achieving 71 dB gain, 11 MHz GBW, 45° phase margin, and 20 V/µs slew rate while optimizing frequency response and stability.
